# 아람글 1차 실사용 검증 문장 세트

## 목적

Production 배포 후 실제 화면에서 아람글의 핵심 교정 영역을 빠르게 검증하기 위한 수동 Acceptance Test V1이다.

- 이 문서는 **기대 결과(oracle)** 이다.
- 현재 코드가 모든 케이스를 통과한다는 의미가 아니다.
- 실제 결과가 기대 결과와 다를 때만 결함으로 기록하고 수정한다.
- 정상 문장은 오탐(false positive) 여부를 확인하기 위해 포함한다.

## 판정 기준

- **PASS**: 기대 결과와 일치하고 수정 제안/설명이 자연스럽다.
- **FAIL**: 기대 결과와 다르거나, 정상 문장을 잘못 수정하거나, 오류 위치가 잘못 표시된다.
- **REVIEW**: 사전/문맥에 따라 자동 판정을 보류해야 하는 사례. 무리한 자동 교정을 하지 않는지가 핵심이다.

## 실행 순서

1. Production 배포 후 A01~A10을 먼저 검사한다.
2. B01~B08로 오탐을 확인한다.
3. C01~C06에서 문맥형 교정과 보류 동작을 확인한다.
4. D01~D08에서 사전 증거 및 경계 판단을 확인한다.
5. E01~E06에서 여러 오류가 한 문장에 섞였을 때 결과를 확인한다.
6. FAIL만 별도 이슈로 기록한다.
7. REVIEW는 자동 교정을 강행하지 않았는지 확인한다.

## 1차 종료 조건

- 핵심 CORRECTION 사례에서 기대 결과가 일치한다.
- VALID 사례에서 불필요한 수정이 발생하지 않는다.
- REVIEW 사례에서 근거가 부족한 자동 교정을 강행하지 않는다.
- 복합 문장에서 오류 위치와 수정 결과가 서로 충돌하지 않는다.
- 실제 결함이 발견되면 해당 결함을 수정한 뒤 기존 전체 테스트와 이 검증 세트를 다시 확인한다.
