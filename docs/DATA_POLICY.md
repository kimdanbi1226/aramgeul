# 아람글 데이터·출처 정책 초안

> 작성 기준: 2026-10-01 공식 기관 공개 자료 확인 결과
>
> 이 문서는 아람글이 맞춤법·띄어쓰기·표현 검사와 사전/용어 정보를 결합할 때 사용할 데이터 출처와 이용 조건을 정리한 내부 설계 문서다. API를 실제 연결하기 전에 이용 조건과 라이선스를 확인하는 것을 원칙으로 한다.

## 1. 출처별 역할

| 출처 | 아람글에서의 역할 | 판단 성격 |
|---|---|---|
| Bareun | 맞춤법·띄어쓰기·문장 오류의 1차 검사 엔진 | 검사 결과 |
| 국립국어원 어문 규범 | 한글 맞춤법·표준어·외래어 표기 등 규범 기준 | 규범 근거 |
| 표준국어대사전 | 표제어·품사·뜻·용례 등 | 표준 사전 정보 |
| 우리말샘 | 폭넓은 어휘·신어·전문/생활 어휘 보완 | 보조 사전 정보 |
| 온용어 | 전문 분야 용어·분야·정의·사용 예시·관련 용어 | 전문 용어 정보 |
| 한국어기초사전 | 뜻·품사·예문 등 보조 정보 | 보조 사전 정보 |
| OpenAI API | 문맥 설명·사용자에게 이해하기 쉬운 설명 생성 등 | 보조 설명 계층 |

## 2. 기본 원칙

1. 사전에 등재되어 있다는 사실만으로 해당 표현을 '맞는 표현'이라고 판정하지 않는다.
2. 사전에 없다는 사실만으로 '틀린 표현'이라고 판정하지 않는다.
3. 규범 위반, 표준어 여부, 사전 등재 여부, 전문 용어 여부, 문체/격식상의 권장 여부를 서로 다른 정보로 취급한다.
4. 서로 다른 출처가 다른 정보를 제공하면 출처의 역할과 권위를 기준으로 판단하며, 임의로 하나의 출처를 덮어쓰지 않는다.
5. 원문에 없는 효능·의미·규범을 AI가 만들어내지 않도록 한다.
6. 출처가 필요한 설명에는 실제 근거 출처를 표시할 수 있도록 결과 데이터에 source/source_url/version 정보를 보존한다.

## 3. 현재 확인된 이용 조건

### 3.1 표준국어대사전·우리말샘

국립국어원 공식 저작권 정책에서 표준국어대사전과 우리말샘의 별도 표시가 없는 자료는 '크리에이티브 커먼즈 저작자표시-동일조건변경허락 2.0 대한민국(CC BY-SA 2.0 KR)'에 따라 이용할 수 있다고 안내한다.

- 상업적 이용 가능
- 저작자 표시 필수
- 자료를 변경하여 새로운 저작물을 만들 경우 동일 조건으로 배포해야 함
- 이미지·동영상·음악·소리·발음 등 멀티미디어는 별도 정책을 확인해야 함
- 텍스트 자료 중 출전이 있는 용례는 원저작자가 저작권을 보유하므로 별도의 이용 허락이 필요할 수 있음

따라서 아람글에서는 사전의 텍스트 전체를 무분별하게 복제·저장하는 방식보다 API 조회 결과를 필요한 범위에서 활용하고, 원문 용례를 서비스에 재노출할 경우 별도 권리 확인을 거친다.

### 3.2 한국어기초사전

한국어기초사전은 별도 명시가 없는 자료에 CC BY-SA 2.0 KR을 적용한다고 안내한다.

- 상업적 이용 가능
- 저작자 표시 필수
- 변경한 자료는 동일조건변경허락으로 배포
- 멀티미디어 자료는 개별 정책 확인

Open API 인증키가 필요하며 공식 안내에는 서비스 요청이 하루 50,000건까지라고 명시되어 있다.

### 3.3 온용어

온용어 Open API는 회원 가입 후 인증키를 신청하여 사용한다. 검색 결과에는 개별 용어의 kr_gvrn_lcns_ty(공공누리 유형)가 포함될 수 있다.

공공누리 유형은 자료별로 이용 범위가 다르므로, 온용어 데이터를 저장하거나 사용자에게 재표시할 때는 개별 결과의 라이선스 유형을 함께 확인한다.

- 1유형: 출처 표시 + 상업적/비상업적 이용 + 변경 가능
- 2유형: 출처 표시 + 비상업적 이용 + 변경 가능
- 3유형: 출처 표시 + 상업적/비상업적 이용 + 변경 금지
- 4유형: 출처 표시 + 비상업적 이용 + 변경 금지

따라서 온용어 전체를 하나의 라이선스로 취급하지 않는다.

## 4. API 키 보안

- 인증키는 브라우저의 HTML/JavaScript에 넣지 않는다.
- GitHub 저장소에 실제 키를 커밋하지 않는다.
- 서버 환경변수로 관리한다.
- 공개 저장소에는 키가 아니라 변수명만 둔다.
- 현재 Bareun도 이 원칙에 따라 BAREUN_API_KEY 서버 환경변수를 사용하도록 구성되어 있다.
- 국립국어원 계열 API를 추가할 때도 동일한 서버 중계 구조를 사용한다.

## 5. 출처 우선순위 초안

검사 결과의 '정답'과 사전 정보의 '근거'를 분리한다.

### 규범/오류 판단

1. 국립국어원 어문 규범 및 해당 규범을 반영한 검증 규칙
2. Bareun의 교정 결과 및 설명 데이터
3. 사전 정보는 어휘·의미·용례를 보조하는 근거로 사용

### 어휘/의미 정보

1. 표준국어대사전
2. 우리말샘
3. 한국어기초사전
4. 온용어(전문 용어 문맥)

단, 이 순서는 '어느 사전이 더 좋은가'를 의미하지 않는다. 각 데이터의 역할이 다르므로 문맥에 따라 적용한다.

## 6. 우리말샘의 특별 취급

우리말샘은 표준국어대사전과 동일한 방식으로 '표준어 판정 사전'처럼 사용하지 않는다.

우리말샘에 등재되었는지 여부와 표준어 여부는 별도 필드로 관리한다.

예:
- dictionary_presence: 등재 여부
- standard_status: 표준어 관련 정보
- expert_review: 전문가 감수 정보가 있는지
- norm_status: 규범 관련 정보
- register: 문체/사용 영역 정보

이를 통해 '사전에 있음 = 무조건 정답'이라는 잘못된 판정을 방지한다.

## 7. 아직 확정하지 않은 항목

다음 단계에서 공식 문서를 추가 확인한 후 확정한다.

- 표준국어대사전/우리말샘 Open API의 세부 요청 한도
- API 결과의 저장·캐싱 허용 범위
- API 결과를 아람글 화면에 재표시할 때 필요한 출처 표시 형식
- API 결과를 내부 DB에 장기 저장할 수 있는 범위
- 상업 서비스에서의 이용 조건
- 온용어의 개별 공공누리 유형에 따른 저장·변형·재배포 처리
- 데이터 갱신 주기와 버전 관리 방식

## 8. 구현 전 원칙

위 항목이 확정되기 전에는 국립국어원 데이터를 아람글의 영구 DB로 대량 복제하지 않는다.

API 연결 시에는 우선 다음 형태의 서버 계층으로 만든다.

사용자 입력
→ 아람글 서버
→ Bareun / 국립국어원 API
→ 출처별 원자료 정규화
→ 규칙·우선순위 판단
→ 결과 + 근거 출처
→ 사용자 화면

이 구조를 유지하면 향후 API가 추가되거나 정책이 변경되어도 검사 엔진과 데이터 출처 계층을 분리할 수 있다.
