# 아람글 형태소 분석기 후보 비교·선정 기준

## 목적

아람글의 규칙 엔진은 특정 형태소 분석기에 종속되지 않는다. 후보 분석기의 분석 결과를 공통 토큰 모델로 정규화한 뒤 Golden Test Set으로 비교하고, 결과가 확인된 후 실제 의존성을 추가한다.

## 현재 후보

| 후보 | 구현 | 라이선스 | 아람글 적합성 확인 포인트 |
|---|---|---|---|
| MeCab-Ko | Rust / Node.js / WASM / Python | MIT 또는 Apache-2.0, 사전 데이터 Apache-2.0 | Node/WASM 연동, 사용자 사전, 의존 명사·보조 용언 분석 |
| KOMORAN | Java, PyKOMORAN 제공 | Apache-2.0 | 서버 분리 운용, 분석 품질, 배포 복잡도 |
| Khaiii | C++ / Python | Apache-2.0 | 분석 품질, 현재 유지보수 상태, 서버 배포 |
| Kiwi | C++ 기반, Python 등 연동 | LGPL-3.0 | 분석 품질, 라이선스 조건, 서버 구조와의 결합 방식 |

> 라이선스는 코드 프로젝트 기준이다. 실제 배포 전에는 사용하는 사전·모델·데이터의 개별 라이선스도 별도로 확인한다.

## 현재 1차 후보

**MeCab-Ko를 1차 후보로 두고 테스트한다.**

이것은 최종 선정이 아니다. 현재 아람글의 서버가 JavaScript 계열이고, MeCab-Ko가 Node.js와 WebAssembly 바인딩 및 사용자 사전을 제공한다는 점 때문에 먼저 검증할 가치가 있다는 의미다.

## 평가 기준

점수로 순위를 매기지 않고, 다음 조건을 통과하는지를 확인한다.

1. **형태소 분해**
   - 의존 명사: 수, 것/거, 만큼, 뿐, 데, 시, 년 등
   - 조사: 만큼, 뿐, 밖에, 부터 등
   - 보조 용언: 보조 용언 여부를 구분할 수 있는가
   - 부정 부사: 안, 못
   - 활용: 되다의 활용형과 어미를 구분할 수 있는가

2. **문맥 구분**
   - 같은 표면형이 조사/의존 명사 등으로 달라지는 경우를 후보 정보로 보존할 수 있는가
   - 여러 분석 후보가 있을 때 ambiguity를 잃지 않는가

3. **아람글 데이터 모델과의 연결**
   - lemma
   - POS
   - morphemes
   - features
   - start/end
   - confidence
   를 공통 모델로 변환할 수 있는가

4. **배포**
   - 현재 API 서버에서 안정적으로 실행할 수 있는가
   - 서버리스 환경을 사용할 경우 네이티브 바이너리 의존성이 문제되지 않는가
   - cold start와 메모리 사용량이 허용 범위인가

5. **사전 확장**
   - 아람글 전용 용어·신조어·제품명 등을 사용자 사전으로 추가할 수 있는가
   - 사전 변경이 기존 Golden Test를 깨뜨렸을 때 추적할 수 있는가

6. **라이선스**
   - 코드 라이선스
   - 기본 사전/모델 라이선스
   - 사용자 사전의 출처와 재배포 조건
   을 각각 기록한다.

## 탈락 조건

다음 중 하나라도 해결되지 않으면 기본 형태소 분석기로 채택하지 않는다.

- 상업 서비스 배포 조건을 명확히 확인할 수 없음
- 필요한 형태소/POS 정보를 공통 모델로 변환할 수 없음
- Golden Test에서 핵심 문법 기능을 반복적으로 잘못 분석함
- 서버 배포 구조가 현재 아람글의 운영 방식과 맞지 않음
- 데이터 라이선스 또는 재배포 조건이 불명확함

## 테스트 순서

1. 동일 입력을 모든 후보에 전달한다.
2. 원시 분석 결과를 그대로 저장한다.
3. 공통 토큰 모델로 정규화한다.
4. Golden Test의 기대 문법 기능과 대조한다.
5. 후보별 실패 사례를 기록한다.
6. 핵심 실패가 해결되는지 사용자 사전/설정으로 재검증한다.
7. 그 후에만 기본 분석기를 확정한다.

## 중요한 원칙

형태소 분석기의 분석 결과가 곧 맞춤법 판정은 아니다.

- 형태소 분석기: 문장의 구조와 형태소 후보를 제공
- 아람글 규칙 엔진: 그 구조를 이용해 규칙 적용
- 국립국어원 기준: 규범 판단의 근거
- Bareun: 교정 후보 및 설명 보조

따라서 형태소 분석기의 결과만으로 '맞다/틀리다'를 확정하지 않는다.
